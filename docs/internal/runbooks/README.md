# Host runbooks

Step-by-step operator procedures for the Windows hosts in the reference deployment. Each one is
written so an agent can follow it on its own host. For example: "Start A2A using agy-start.md".

| Runbook | Use it to |
|---|---|
| [agy-install.md](agy-install.md) | install and configure A2A for Antigravity (`agy`) from scratch |
| [agy-start.md](agy-start.md) | start, check, stop and troubleshoot the Antigravity stack |
| [codex-install.md](codex-install.md) | install and configure A2A for a Codex agent |
| [codex-start.md](codex-start.md) | start, verify and restart the Codex stack |

Linux and macOS hosts use [docs/GETTING-STARTED.md](../../GETTING-STARTED.md) and the per-runtime
setup guides in [docs/telegram/](../../telegram/).
